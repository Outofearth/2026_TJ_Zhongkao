## 📋 各报告内容概要

### 标签1：中考五年历史（2021-2025）
- 天津中考总分说明（2021年590分 vs 2022-2025年800分）
- 表1：近五年5分一档一分一段对照表（含位次范围）
- 表2：各分数段对应录取学校及特色班（三年对照）
- 表3：特色班专项表（小卷实验班/王克昌班等）
- 2025年/2024年/2023年各高中录取分数线
- 市九所及河西区招生规模五年变化
- 位次+分数双维度填报建议
- 关键趋势分析

### 标签2：2026预测
- 2026年中考关键时间轴（体育/听力/笔试/小卷）
- 考生规模与一分一段预测（~13.8-14万）
- 市九所录取分数线预测
- 河西区招生规模预测
- 分段报考策略（冲顶段→普高段）
- 河西区考生冲-稳-保策略
- 常见问题QA

### 标签3：高考11年分析（2015-2025）
- 天津高考人数与录取率11年变化
- 清北在津录取规模
- 市九所高考成绩总览（985/211/一本率估算）
- 河西区主要高中高考成绩
- 市九所清北录取人数演变（11年完整表）
- 985/211录取梯队对比
- 中考位次→高考去向对照表
- 11年核心趋势

### 标签4：小卷实验班（2020-2025）
- 市五所实验班设置总览对比表
- 各校实验班详解（南开/一中/耀华/新华/实验）
- 小卷招生策略变化时间线
- 分班与教育资源配置
- 高考去向与口碑
- 王克昌班真相说明
- 报考策略建议

### 标签5：高中地图（天津市高中分布）
- 基于 Leaflet 的天津市区高中分布地图（高德底图），覆盖**市内六区 + 海河教育园区**
- 按属性用不同标记区分：**★ 市属 / ● 区属 / ○ 民办**
- 点击学校弹出窗口，展示 **2023–2025 年官方录取分数线**，并换算全市累计位次（一分一段表）
- 控制面板支持**搜索学校、按市属/区属/民办筛选、对比分数线表格**
- **右键收藏**学校、拖拽浮窗、在地图间**连线**对比，收藏与状态保存在浏览器本地
- 与报告其余部分**样式隔离**（iframe 内嵌），功能完整、互不干扰
- ⚠️ 打开此标签页需联网加载地图瓦片与 Leaflet 库

## ⚠️ 数据可靠性说明

报告中每项数据均标注了来源可信度：

| 标签 | 含义 | 例 |
|------|------|----|
| ✅ **多源** | 3个以上独立来源交叉核实 | 考生人数、考试时间、招生计划 |
| ⚠️ **1-2源** | 仅1-2个来源，需谨慎参考 | 各校清北人数、985率估算 |
| 🔶 **估算** | 基于公开数据推算 | 5分一档估算值、招生规模估测 |

**核心原则：** 数据来源须≥3个独立来源交叉核实，不足3个的已在报告中标注。
